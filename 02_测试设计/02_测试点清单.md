# 测试点清单

文档编号：TEST‑POINT‑RYVUE‑001

参考依据：《00_模拟需求文档.md》、《01_测试方案 / RuoYi‑Vue 测试方案.md》

> 说明：本文件提取各模块测试点，作为编写测试用例的输入；分为正向、边界异常、数据库一致性、接口、安全、兼容性测试点。

## 1 登录模块

### 正向测试点

1. 输入正确用户名、密码，登录成功跳转首页，获取 JWT 令牌
2. 点击退出登录，销毁 token，跳转至登录页面
3. token 过期后访问页面，自动跳转登录页

### 异常 & 边界测试点

1. 用户名为空提交登录
2. 密码为空提交登录
3. 用户名错误、密码错误登录
4. 使用状态为禁用的账号尝试登录

### 安全测试点

1. 绕过登录直接输入首页 url 访问系统
2. 使用伪造 token 访问业务页面

## 2 用户管理模块

### 正向测试点

1. 填写全部合法信息新增用户，保存成功
2. 修改用户昵称、手机号、邮箱、角色信息保存生效
3. 将用户设置为禁用，账号无法做新的登录
4. 删除用户，列表不再展示该用户
5. 根据用户名、部门、状态做条件筛选查询
6. 正常切换分页（pageNum=1、pageSize=10）

### 边界 & 异常测试点

1. 用户名字符达到最大长度、超过最大长度
2. 新增用户名与已有用户名重复
3. 手机号输入非法格式（字母、特殊符号、位数不对）
4. 邮箱输入非法格式
5. 新增用户不选择部门直接保存
6. 新增用户不分配角色直接保存
7. 分页参数传入负数、0、超大数字
8. 快速连续多次点击新增保存按钮，验证重复提交

### 数据库一致性测试点

1. 新增用户后，核对 sys_user 表新增记录，del_flag=0
2. 用户禁用，数据库 status 字段更新为 1
3. 删除用户，del_flag 更新为 1；列表查询过滤已删除数据
4. 编辑用户后，对应字段同步更新数据库

### 接口 & 安全测试点

1. 不带 token 调用用户列表接口
2. 普通用户 token 调用管理员用户列表接口（越权验证）
3. 昵称输入 XSS 脚本字符，观察页面渲染
4. 传入异常参数，校验后端是否直接抛出堆栈 500 报错

## 3 角色管理模块

### 正向测试点

1. 新增角色，填写合法角色名称、角色标识，保存成功
2. 给角色分配菜单权限并保存
3. 修改角色基础信息、修改分配的菜单权限保存
4. 启用 / 禁用角色
5. 删除未被用户绑定的角色

### 边界 & 异常测试点

1. 角色名称重复提交
2. 角色标识重复提交
3. 角色名称为空、角色标识为空保存
4. 删除已经被用户绑定使用的角色

### 数据库一致性测试点

1. 新增角色，sys_role 表新增记录
2. 分配菜单权限后，sys_role_menu 生成对应关联数据
3. 用户绑定角色，sys_user_role 生成关联记录

### 安全测试点

1. 修改角色权限后，已登录用户，验证权限是否实时生效
2. 低权限账号调用角色管理相关接口

## 4 菜单管理模块

### 正向测试点

1. 新增目录、菜单、按钮权限
2. 编辑已有菜单信息
3. 删除未被引用的菜单
4. 调整菜单上下级层级关系

### 异常测试点

1. 菜单名称为空保存
2. 设置重复路由地址
3. 删除正在被角色绑定使用的菜单

### 数据库一致性测试点

1. 新增 / 编辑菜单，sys_menu 表数据同步变更

### 安全测试点

1. 没有菜单权限的账号，直接访问菜单对应接口

## 5 部门管理模块

### 正向测试点

1. 新增一级部门、新增子部门
2. 编辑部门名称、排序
3. 停用部门
4. 删除无下属、无关联用户的部门

### 异常测试点

1. 部门名称为空保存
2. 删除存在子部门的父部门
3. 删除下面还绑定用户的部门

### 数据库一致性测试点

1. 新增、编辑、停用部门，sys_dept 表字段同步更新

## 6 系统监控‑在线用户

### 正向测试点

1. 查看当前在线登录用户列表
2. 执行强制下线操作，用户会话失效

### 异常测试点

1. 对已经离线的用户执行强制下线

## 7 定时任务模块

### 正向测试点

1. 新增定时任务，填写合法 cron 表达式保存
2. 编辑定时任务、执行一次任务
3. 启用、暂停定时任务、删除任务

### 边界异常测试点

1. 填写非法 cron 表达式，提交保存
2. cron 边界时间配置

## 8 接口专项测试点（通用）

1. 接口携带正常 token，正常参数请求
2. 请求头移除 token 发起请求
3. 使用过期 token 访问接口
4. 篡改 token 内容访问业务接口
5. 请求传入特殊符号、超长字符串、负数等异常参数

## 9 兼容性测试点

1. Chrome：各模块页面展示，新增、编辑、删除、导出 Excel 功能
2. Edge：页面布局、按钮交互、导出 Excel
3. Firefox：表单、日期组件、导出按钮、弹窗样式

## 10 安全专项测试点汇总

1. XSS 脚本输入测试
2. 未授权访问（不带 token 访问业务接口）
3. 垂直越权：低权限访问管理员接口
4. 水平越权：同角色访问他人私有数据
5. 校验后端异常是否直接返回 Java 堆栈报错信息
