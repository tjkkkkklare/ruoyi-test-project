# 若依管理系统（RuoYi-Vue）功能测试项目

> 本项目是我个人用于练习软件测试全流程的实战项目，独立完成了从需求分析到测试报告输出的完整测试周期。

## 项目简介

若依（RuoYi）是国内最流行的 Java 开源后台管理系统之一，基于 Spring Boot + Vue3 的前后端分离架构，采用 RBAC 权限模型，广泛应用于企业级后台管理系统的开发。

我将其作为测试练习对象，**独立完成测试计划、测试用例设计、测试执行、缺陷跟踪及测试报告输出的全流程测试工作**。

## 典型缺陷展示

### 1. XSS 注入风险（严重）

- **发现位置：** 登录页面用户名输入框
    
- **操作：** 输入 `<script>alert(1)</script>`，页面弹出窗口
    
- **风险：** 可被用于盗取用户信息或伪造请求
    
- **状态：** 待修复
    

### 2. 普通用户越权访问（严重）

- **发现位置：** 用户管理页面 / 角色管理页面
    
- **操作：** 普通用户直接输入 URL 访问管理页面
    
- **风险：** 普通用户可查看/操作管理员数据
    
- **状态：** 待修复
    

### 3. 水平越权风险（严重）

- **发现位置：** 用户数据接口
    
- **操作：** 用户A的 Token 可获取用户B的数据
    
- **风险：** 用户数据可能被其他用户非法获取
    
- **状态：** 待修复
    

## 测试结论

当前版本**存在较多安全漏洞和数据一致性问题，不建议直接上线**。

|评估维度|结论|
|---|---|
|基本功能可用性|✅ 核心业务流程基本可用|
|安全风险|❌ 存在 XSS 注入、越权访问等高危漏洞|
|数据一致性|⚠️ 部分关联数据（部门/角色/用户）存在不一致|
|上线建议|❌ 修复严重缺陷后方可上线|

## 后续改进建议

1. **安全加固：** 统一增加 XSS 过滤，完善权限校验（`@PreAuthorize`）
    
2. **数据一致性：** 级联删除时同步清理关联数据
    
3. **异常处理：** 全局异常拦截，不返回 Java 堆栈信息
    
4. **会话管理：** 禁用账号/角色时强制下线已登录会话
