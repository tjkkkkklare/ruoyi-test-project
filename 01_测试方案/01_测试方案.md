# RuoYi-Vue 后台管理系统 测试方案

文档编号：TEST-PLAN-RYVUE-001

依据文档：《00_模拟需求文档.md》

## 1 概述

### 1.1 测试目标

依据整理的模拟需求文档，对 RuoYi-Vue 后台管理系统开展全流程测试，尽可能发现功能缺陷、权限安全风险、交互异常；验证系统功能符合业务需求，输出完整测试交付物，形成标准化软件测试项目实训案例。

### 1.2 测试范围

✅纳入测试模块

1. 登录鉴权模块
2. 用户管理模块
3. 角色管理模块
4. 菜单管理模块
5. 部门管理模块
6. 在线用户监控（系统监控）
7. 定时任务模块

❌不纳入本次测试范围

1. 性能压力测试、并发测试
2. 移动端适配测试
3. 服务器运维、数据库底层优化
4. 第三方插件底层源码测试

### 1.3 测试环境

- 前端地址：[http://localhost:82](https://link.wtturl.cn/?target=http%3A%2F%2Flocalhost%3A82&scene=im&aid=582478&lang=zh "autolink")
- 后端接口地址：[http://localhost:8080](https://link.wtturl.cn/?target=http%3A%2F%2Flocalhost%3A8080&scene=im&aid=582478&lang=zh "autolink")

### 1.4 测试工具清单

1. 功能测试：Chrome、Edge、Firefox
2. 接口测试：Postman
3. 数据库校验：DBeaver
4. 缺陷管理：禅道（本地部署）
5. 文档管理：Obsidian（Markdown）
6. 截图素材：系统截图工具

## 2 测试类型与测试策略

1. **功能测试**
    
    使用等价类划分、边界值分析、场景法、错误推测法设计用例，覆盖正常业务场景、异常输入场景。
2. **接口测试**
    
    调用 RESTful 接口，验证正常传参、异常参数、无 Token、低权限 Token 访问等场景。
3. **数据一致性测试**
    
    前端完成增删改操作后，查询 MySQL 数据表，校验字段同步情况。
4. **基础安全测试**
    
    未授权访问、垂直 / 水平越权、XSS 输入测试、异常报错信息泄露校验。
5. **浏览器兼容性测试**
    
    在 Chrome、Edge、Firefox 验证页面展示、表单提交、弹窗、导出功能。

## 3 测试准入标准

满足以下全部条件，方可启动正式测试：

1. 前后端服务正常启动，所有被测模块页面可正常访问；
2. 数据库初始化完成，基础角色、部门、管理员账号数据存在；
3. 《模拟需求文档》定稿，作为统一测试依据；
4. 禅道、Postman、DBeaver 测试工具调试连通；
5. 冒烟测试执行通过，不存在阻断性缺陷。

## 4 测试执行顺序

1. 冒烟测试 → 2. 功能测试 → 3. 接口专项测试 → 4. 安全测试 →5. 兼容性测试 →6. 第一轮缺陷回归 →7. 全量抽样回归

## 5 缺陷分级标准（企业通用规范）

表格

|缺陷等级|定义|处理优先级|
|---|---|---|
|严重|权限失效、越权访问、会话不失效、非法参数导致服务 500、阻断核心业务流程|最高，优先修复，暂停相关模块测试|
|一般|前端表单校验缺失、数据展示错误、逻辑删除失效、功能偶尔异常|高，本轮测试周期内修复|
|轻微|UI 样式错位、文案错误、交互体验不佳、无业务风险|低，可根据实际情况安排修复|

## 6 测试准出标准

全部满足才可结束本轮测试：

1. 所有**严重、一般级别缺陷修复完成，并通过回归测试；**
2. 全部测试用例执行完毕，完成用例记录；
3. 不存在阻断业务的遗留严重缺陷；
4. 交付完整文档：需求文档、测试方案、测试点、测试用例、缺陷清单、测试报告。

## 8 风险与应对措施

1. 风险：需求存在歧义
    
    应对：记录疑问点，参照通用 RBAC 后台业务规则判定，在文档备注说明；
2. 风险：缺陷修复引入新 bug
    
    应对：缺陷回归时，同步测试周边关联功能；最终执行一轮全量抽样回归；
3. 风险：测试环境不稳定，服务频繁崩溃
    
    应对：重启前后端服务，重新初始化数据库基础数据。
